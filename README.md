# Portal de Investigación SGI · UNAH

Portal público temático de proyectos de investigación registrados en el
Sistema de Gestión de la Investigación (SGI) de la UNAH.

## Contenido

- `index.html` — portal interactivo (catálogo embebido)
- `data/portal-data.json` — catálogo público del portal
- `portal-investigacion-assets/` — logos, sellos y fondo institucional

## GitHub Pages

El sitio se publica desde la rama `main` (carpeta raíz).

Este repositorio contiene solo el sitio estático público. La regeneración
del catálogo se hace fuera de este repo, en el entorno local del SGI.
